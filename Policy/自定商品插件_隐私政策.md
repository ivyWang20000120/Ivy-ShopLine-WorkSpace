# 自定商品 — 隐私政策

本政策仅适用于自定商品（以下简称“本插件”或“我们”）所提供的服务。

最后更新日期：2026-09-14
生效日期：2026-09-14
运营主体：成都思而科软件有限公司（Chengdu Silk Software Co., Ltd.）
官网：https://www.silksoftware.com.cn/

欢迎使用自定商品（以下简称“本插件”或“我们”）。本插件专为 Shopline 商家设计，提供以下主要功能：

- **多位置展示**：在购物车页、迷你购物车（购物车抽屉）以及结账页嵌入自定商品组件，通过可视化选择器配置挂载点。
- **灵活定价**：支持按购物车总价比例计价（百分比定价，自动生成数字商品变体）与固定价格（含按购物车金额区间的阶梯规则）。
- **双组件样式与多语言**：提供标准组件与结账按钮组件两种展示样式，并支持图标、颜色、尺寸、自定义 CSS，以及多语言文案与退款政策链接。
- **订单看板与履行规则**：汇总含自定商品订单数量、金额与转化指标，支持筛选、搜索与导出，并配置自定商品被标记为已履行的时机。

本隐私政策说明我们如何收集、使用、存储、共享和保护商家数据及商家的客户数据，并说明相关权利与选择。

---

## 1. 适用范围

本政策适用于我们通过以下方式提供的服务：

- 在 Shopline 后台安装、授权、配置和使用本插件；
- 与本插件相关的网站、帮助页面和商家支持服务；
- 商家启用的前台功能，例如购物车、迷你购物车与结账页中的自定商品组件；
- 本插件与 Shopline 之间为实现上述功能所需的 API、脚本注入与 Webhook 处理；
- 自定商品创建与变体同步、订单看板查询、导出以及履行状态更新。

---

## 2. 我们在数据处理中的角色

对于店铺经营数据及商家客户数据，通常由商家决定处理目的和方式；我们主要作为商家的服务提供方，按照商家在 Shopline 内授权和指示的范围处理相关数据。对于商家账号信息、计费信息（如有）、客户支持沟通记录、插件运行日志以及安全审计记录，我们可能作为独立的控制者或处理者，以提供、维护和保护本插件为目的处理相关信息。

如果您是商家的客户（终端消费者），并希望就订单、购物车选择或自定商品相关数据行使权利，我们建议您优先联系商家；在适用法律允许的范围内，我们会为商家提供合理协助。

## 3. 我们收集的信息

### 3.1 通过 Shopline 或商家授权收集的信息

根据安装时授予的权限及您使用的功能，我们可能收集：

**（1）店铺与商家账号信息**

- 店铺名称、店铺域名、店铺 ID、商家 ID
- Shopline 为内嵌应用提供的商家后台身份标识
- 插件安装与授权状态、OAuth 令牌或等效凭证（仅存储于服务器端）
- 计费、套餐、订阅或服务激活信息（如有）
- 店铺套餐类型（用于判断是否支持结账页自定义挂载）

**（2）商品与定价配置数据**

- 自定商品标题、SKU 前缀、商品标签（如 `sl-custom-made`）
- 定价模式（百分比 / 固定价格）、费率、最低收费、递增步长、默认价格与金额区间阶梯规则
- 系统为百分比定价自动创建的数字商品变体信息（SKU、价格档位）
- 发布状态、主题挂载点选择器、结账页 URL（路径需包含 `/checkouts/`）

**（3）组件样式与多语言数据**

- 展示样式（标准组件 / 结账按钮组件）、默认勾选设置
- 图标、颜色、尺寸、间距及自定义 CSS
- 多语言文案（标题、启用/禁用描述、结账按钮与链接模板）及退款政策 URL

**（4）订单与客户相关数据**

- 订单编号、订单金额、订单履行状态、下单日期
- 客户邮箱（用于订单看板展示、搜索与导出）
- 自定商品费用、自定商品状态（已选 / 未选）、自定商品履行状态
- 用于计算看板指标所需的汇总数据（含自定商品订单数、平均自定商品金额、订单金额相关性、含自定商品订单占比）
- 购物车总价等用于实时计算保费 / 自定商品费用的金额字段

**（5）履行规则配置**

- 商家选择的履行规则（第一个订单商品完成时 / 整个订单完成时 / 下单后立即履行）

### 3.2 您主动提供给我们的信息

在配置或使用本插件时，您可能提供：

- 您发送给我们的工单、邮件、在线沟通记录及反馈
- 您为排查问题而主动提供的截图、导出文件或附件（如该功能可用）

### 3.3 后台、设备与前台使用信息

当您在 Shopline 后台、本插件相关网页中使用本插件，或顾客在已启用组件的购物车、迷你购物车、结账页与组件交互时，我们可能收集：

- IP 地址、浏览器类型、设备类型、操作系统及访问时间
- 页面路径、来源页面及语言偏好
- 用于会话保持、身份验证、安全、故障排查与性能所需的 Cookie、本地存储、会话标识符或类似技术
- 组件勾选状态、挂载点是否命中、脚本注入与展示回退所需的技术数据

### 3.4 我们一般不收集的信息

除非为提供服务所必需且已获得合法授权，我们不会主动收集与本插件功能无关的敏感个人信息。我们不收集或存储完整支付卡号、CVV 等支付凭证信息；支付处理由 Shopline 或符合合规要求的支付服务商完成，不属于本插件的处理范围。

## 4. 我们如何使用信息

我们仅在提供本插件服务、履行合同、遵守法律义务及维护平台安全所必需的范围内使用数据。主要用途包括：

### 4.1 自定商品展示、定价与 Shopline 集成

- 在商家授权后注入购物车 / 结账脚本，并在配置的挂载点展示自定商品组件
- 根据定价规则实时计算自定商品费用，并创建、更新或匹配对应的自定义商品与变体
- 将顾客勾选结果写入购物车 / 结账流程，使自定商品作为订单行出现在订单中
- 在结账页未配置挂载点或选择器未命中时，按规则回退到默认位置（如 `#main-sidebar`）展示
- 按商家配置的履行规则更新自定商品履行状态
- 生成订单看板指标，并支持按条件筛选、搜索与导出订单数据

### 4.2 安全、验证与风险控制

- 校验授权信息及接口调用的合法性
- 监控异常请求、错误日志、滥用行为及安全风险
- 排查问题、维护稳定性并支持审计追溯

### 4.3 客户支持与产品改进

- 响应商家的咨询、问题反馈及实施支持需求
- 统计使用情况与系统稳定性
- 使用去标识化或聚合数据改进产品性能与体验

### 4.4 法律与合规

- 遵守适用的数据保护法规
- 遵守法律、司法机关、监管部门或政府部门的要求
- 响应关于访问、更正、删除或限制处理的合法请求
- 履行合同、处理争议以及配合审计与合规工作

## 7. 我们如何共享信息

我们不会出售商家数据或商家客户数据。

- **服务提供商**：为交付服务，我们可能与 Shopline 及云托管、数据库、CDN、监控、日志、邮件服务等供应商共享必要数据
- **按您的指示**：当您发布组件、配置挂载点、创建自定义商品或导出订单时，我们会在必要范围内向 Shopline 传输数据，以实现商品创建、脚本注入、购物车/结账展示与订单同步
- **法律或安全需要**：为遵守法律、法院裁决、监管要求或执法部门要求；为保护权利与安全；为防范欺诈、滥用或未经授权的访问
- **企业交易**：在合并、收购、重组、资产出售、融资或类似情形下，数据可能作为交易的一部分被转移；接收方须继续依法处理相关数据

## 8. 数据保留

我们遵循“最小必要、按需保留”的原则。在您卸载本插件或终止服务后，非必要配置数据将在 90 天内删除或匿名化处理；为审计、争议处理或合规所需的数据可能依法保留更长时间。

请注意：本插件在 Shopline 店铺中创建的自定义商品及其变体，卸载后**不会自动删除**。如不再需要，请商家在 Shopline 后台商品列表中自行删除或归档，以免产生冗余商品。

我们采用 HTTPS/TLS、访问控制、身份验证、日志记录、备份与灾难恢复等措施保障数据安全。OAuth/访问令牌仅存储于服务器端，不会暴露给客户端。请注意，任何互联网传输或电子存储方式均无法做到绝对安全。
