# 订单报表自定义导出 — 隐私政策

本政策仅适用于订单报表自定义导出（以下简称"本插件"或"我们"）所提供的服务。

最后更新日期：2026-08-06
生效日期：2026-08-06
运营主体：成都思而科软件有限公司（Chengdu Silk Software Co., Ltd.）
官网：[https://www.silksoftware.com.cn/](https://www.silksoftware.com.cn/)



欢迎使用订单报表自定义导出（以下简称"本插件"或"我们"）。本插件专为 Shopline 商家设计，提供以下主要功能：

- **扩展订单报表导出**：在 Shopline 原生订单字段基础上，新增订单确认时间、商品成本价、发货日期、物流商名称、已发货/待发货数量、收货地址国家全称、订单总价汇率等多原生暂未提供的字段，并支持导出全部原生订单字段。
- **多币种导出**：通过调用 Shopline 开放平台接口获取的汇率数据，支持以店铺货币、订单货币、或两者同时展示金额字段。
- **导出方案管理**：商家员工可保存、编辑、重命名、删除已配置好的字段勾选与货币模式组合，方案在店铺内共享。
- **批量发货导入/导出**：商家可上传表格批量将多个订单/商品行标记为已发货，并可选择是否触发客户发货通知邮件。

本隐私政策说明我们如何收集、使用、存储、共享和保护商家数据及商家的客户数据，并说明相关权利与选择。

---

## 1. 适用范围

本政策适用于我们通过以下方式提供的服务：

- 在 Shopline 后台安装、授权、配置和使用本插件；
- 与本插件相关的网站、帮助页面和商家支持服务；
- 本插件与 Shopline 之间为实现上述功能所需的 API 调用（包括用于读取订单数据、市场/汇率数据的 Admin REST API）；
- 订单报表导出文件的生成、存储与下载；
- 批量发货导入文件的处理。

---



## 2. 我们在数据处理中的角色

对于订单中包含的店铺经营数据及商家客户数据（如订单明细、收货地址等），通常由商家决定处理目的和方式；我们主要作为商家的服务提供方，按照商家在 Shopline 内授权和指示的范围处理相关数据。对于商家账号信息、计费信息（如有）、客户支持沟通记录、插件运行日志、生成的导出文件、已保存的导出方案以及安全审计记录，我们可能作为独立的控制者或处理者，以提供、维护和保护本插件为目的处理相关信息。

如果您是商家的客户（终端消费者），并希望就您订单中的个人数据行使相关权利，我们建议您优先联系商家；在适用法律允许的范围内，我们会为商家提供合理协助。

## 3. 我们收集的信息



### 3.1 通过 Shopline 或商家授权收集的信息

根据安装时授予的权限及您使用的功能，我们可能收集：

**（1）店铺与商家账号信息**

- 店铺名称、店铺域名、店铺 ID、商家 ID
- Shopline 为内嵌应用提供的商家后台身份标识
- 插件安装与授权状态、OAuth 令牌或等效凭证（仅存储于服务器端）
- 计费、套餐、订阅或服务激活信息（如有）

**（2）订单与履约数据（用于生成报表，读取自 Shopline）**

- 订单编号、订单状态、订单确认时间
- 商品名称、SKU、成本价、数量、已发货数量、待发货数量
- 发货日期、物流商/承运商名称、运单号
- 订单总价、订单货币、店铺货币、订单对店铺汇率
- 收货地址所在国家全称，以及用户勾选导出的其他 Shopline 原生订单字段

**（3）批量发货导入数据（由商家提供）**

- 订单 ID、SKU、运单号、物流服务商、发货数量
- 商家针对该批次是否向客户发送发货通知邮件的选择

**（4）导出配置与任务记录**

- 已保存的导出方案名称、勾选字段列表、货币模式
- 导出与导入任务记录：任务类型、状态、开始/结束时间、按行统计的结果总览、生成的结果文件



### 3.2 您主动提供给我们的信息

在配置或使用本插件时，您可能提供：

- 您发送给我们的工单、邮件、在线沟通记录及反馈
- 您为排查问题而主动提供的导出文件或附件（如该功能可用）



### 3.3 后台管理、设备与使用信息

当您在 Shopline 后台或本插件相关网页中使用本插件时，我们可能收集：

- IP 地址、浏览器类型、设备类型、操作系统及访问时间
- 页面路径、来源页面及语言偏好
- 用于会话保持、身份验证、安全与性能所需的 Cookie、本地存储、会话标识符或类似技术



### 3.4 我们一般不收集的信息

除非为提供服务所必需且已获得合法授权，我们不会主动收集与本插件功能无关的敏感个人信息。我们不收集或存储完整支付卡号、CVV 等支付凭证信息；支付处理由 Shopline 或符合合规要求的支付服务商完成，不属于本插件的处理范围。

## 4. 我们如何使用信息

我们仅在提供本插件服务、履行合同、遵守法律义务及维护平台安全所必需的范围内使用数据。主要用途包括：

### 4.1 报表导出与 Shopline 集成

- 根据商家选择的导出范围与字段，从 Shopline 读取订单及商品数据以生成导出文件，包含原生字段及插件新增字段
- 调用 Shopline Admin REST API（市场/汇率相关接口）以计算多币种导出所需的换算金额
- 存储商家自定义的导出方案（字段勾选与货币模式），便于在店铺内复用与共享
- 处理上传的批量发货文件，将行数据与对应订单/SKU 匹配并更新发货状态，并在商家选择开启时触发 Shopline 的客户通知邮件
- 生成并保留导出/导入任务记录（状态、行统计、结果文件），便于商家追踪进度并重新下载结果



### 4.2 安全、验证与风险控制

- 校验授权信息及接口调用的合法性
- 监控异常请求、错误日志、滥用行为及安全风险
- 排查问题、维护稳定性并支持审计追溯



### 4.3 客户支持与产品改进

- 响应商家的咨询、问题反馈及实施支持需求
- 统计使用情况与系统稳定性
- 使用去标识化或聚合数据改进产品性能与体验



### 4.4 法律与合规

- 遵守适用的数据保护法规
- 遵守法律、司法机关、监管部门或政府部门的要求
- 响应关于访问、更正、删除或限制处理的合法请求
- 履行合同、处理争议以及配合审计与合规工作

我们遵循"最小必要、按需保留"的原则。在插件仍处于安装状态期间，导出/导入任务记录及其结果文件、已保存的导出方案会予以保留，以便商家查阅历史导出记录。在您卸载本插件或终止服务后，配置数据（已保存的导出方案）及任务记录将在 90 天内删除或匿名化处理，除非适用法律要求更长的保留期限。
